# Clinic Booking System

## 📌 Project Description
This project is a simple, relational database for managing a **Clinic Booking System** using **MySQL**. It models real-world operations such as managing doctors, patients, departments, and appointments, including a many-to-many relationship between patients and doctors.

## 📂 Features
- Department, Doctor, Patient, and Appointment tables
- Proper use of Primary Keys, Foreign Keys, Unique, and NOT NULL constraints
- Sample data for testing
- Many-to-many relationship using a junction table (`PatientDoctor`)
- One-to-many relationship between patients and appointments
